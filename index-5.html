ABOUT THE PROJECT

Small quizzes. Big learning.

Quiz Master is an interactive learning game built with a responsive frontend and a Python backend.

🎯

How to play

Choose a category, answer 15 questions, review instant feedback and save your final score.

🔊

Voice mode

Turn voice mode on to hear questions and feedback. Voice availability depends on your browser and device.

🐍

Python backend

Flask provides question and score APIs. Scores are stored in a local JSON file.

💜

Built for mobile

The layout adapts to small screens, so you can play directly in your Android browser.
